
# Финальный отчёт: 4 сайта доставки еды в Воронеже
# Дата: 2026-08-16

## 1. sushi_time (sushi-time.ru)
- **Домен:** sushi-time.ru (xn----8sbwgpzjf9b.xn--p1ai)
- **Стратегия:** HTTP (requests)
- **Schema.org:** да, itemprop="name", itemprop="description", itemprop="image"
- **Вес:** span#vess_preview_XXXX (XXXX = data-id), формат "900 гр"
- **Цена:** span.sale-price-current (JS-rendered, в статике не всегда есть)
- **data-title:** название блюда
- **data-category-name:** категория
- **data-id:** ID товара
- **Реальный вес:** ДА (в граммах)
- **Проблемы:** цены JS-rendered, нужно Playwright для точных цен

## 2. ninja_food (ninjafood.su)
- **Домен:** ninjafood.su
- **Стратегия:** Playwright (JS-rendered)
- **CMS:** Bitrix
- **Цены:** JS-rendered, видны в DOM после рендера
- **Реальный вес:** НЕТ (веса нет в HTML, только цены)
- **Проблемы:** нет весов, Bitrix CMS, JS-rendered цены

## 3. pizzeria_cuba (pizzeriacuba.ru)
- **Домен:** pizzeriacuba.ru
- **Стратегия:** HTTP (requests)
- **API:** https://vsem-edu-oblako.ru/singlemerchant/api/getHomeProducts
- **Реальный вес:** НЕТ (item_massa пустой)
- **Проблемы:** нет реальных весов, цены в JSON как {"size_id":"price"}

## 4. dodopizza (dodopizza.ru)
- **Домен:** dodopizza.ru
- **Стратегия:** Playwright + API intercept
- **API:** https://dodopizza.ru/api/v5/menu/delivery/countries/643/localities/00000193-0000-0000-0000-000000000000
- **Реальный вес:** ДА (foodValue.weight)
- **Проблемы:** cookies не нужны для API, 187 items, много вариаций
